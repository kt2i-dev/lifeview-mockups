11/13/2026

  • Start page reorganized: HR, Payroll and Benefits screens, the review checklist and these updates each have their own page. Checklist items now link to the widget, button or template section that explains them. Review checklist
  • Coded values show “Code - Description” in View, as LifeView does (“10000 - CITY OF LONG BEACH”), not the description alone: the CodeDescriptionConcat block with the code and the description the GET returns. Every mockup shows it. Custom widgets
  • Renamed blocks: CodeDescriptionExpression → CodeDescriptionConcat, DateExpression → DateFormat. CodeDescriptionConcat · DateFormat
  • StickyPageHeader is the header of every detail and edit screen (replaces FloatingActionButtons, which is gone): Title (mandatory), Subtitle and BackLabel (optional; blank = “Back”) inputs, ← Back built in (handle its event with the screen’s back action), the buttons in ButtonPlaceholder. Piloted on TaxControl_Detail. Custom widgets · Template
  • No Save button. Update saves in place, Add saves a new record; a screen shows only what its endpoint supports (Add · Update, Update alone, or Add alone). In-form buttons (Add, Update, Previous, Next) stay plain buttons, since block buttons don’t run the form’s validation; ButtonUpdate is to be removed, ButtonAdd stays for lists. Button standard
  • New blocks ButtonSearch / ButtonReset for filter rows, icon then text like every button: Search with a magnifying glass, Reset with the same prohibit icon as Cancel. EffectiveDateFilter uses them and only searches when Search is clicked. ButtonSearch / ButtonReset · EffectiveDateFilter
  • Sorted table headers in an app-table keep white text; the sorted column is bold with a white underline (LongBeachAdmin theme). Review checklist
  • Rollout list: where each block is still needed, from an AI audit of the app (not yet checked). Custom widgets
