Recent updates

What’s new or different in the standard, newest first. Check here before building or reviewing a screen.

11/22/2026

  • Mockups checked against the whole standard; nothing in the standard changed. Fixed where the mockups had drifted from it: list cells now show coded values as “Code - Description” (as CodeDescriptionConcat prints them) and amounts without a currency sign (as FormatDecimal prints them); the Check History, Gross to Net and Dependent Benefits lists’ last column is “Actions”; Check Detail’s line amounts are left-aligned like every other column; detail subtitles use the same “Code - Description”; and Search and Reset sit together in one filter-actions container, so Reset no longer wraps under the filters.

11/21/2026

  • New widget: ProfileTabs, the shared tab strip for the Employee Profile’s HR, Payroll and Benefits sections (Tabs = list of ProfileTabItem, ActiveTabId, ExtendedClass; event TabSelected(TabId)). It holds no state and matches the OutSystems UI Tabs widget’s look. Custom widgets
  • APIPagination has one event: PaginationTriggered(NewStartIndex) replaces NextPage / PreviousPage, and the block works out the new start index itself. It’s mandatory, so every new list must handle it. Each list has one PaginationOnNavigate action that assigns the start index and refreshes. All 18 gateway lists are on it. While a page loads, the Previous · Next row now stays with both buttons disabled instead of disappearing (not yet confirmed in the browser). Custom widgets · List template
  • Employee Profile opens with no arguments. The section and each section’s last tab live in client variables (ProfileSection, ProfileHRTab, ProfilePayrollTab, ProfileBenefitsTab), each backed by a static entity; tab content shows on named static-entity values, not numbers. Employee Profile (notes under the tabs)
  • Detail blocks don’t navigate: DirectDeposit_Detail’s Save and Delete now raise Back, and the host screen navigates, like the other detail blocks. Template
  • StickyPageHeader gets RemoveTopSpace (default False): True sticks it at the very top (ds-sticky-header--no-top). Custom widgets
  • New theme classes: ds-tabs, ds-tabs__item, ds-tabs__item--active (ProfileTabs; theme variables only, nothing in the block’s own style sheet) and ds-sticky-header--no-top. Theme classes
  • Wizards: New Hire and HR1 Change Request are list-based wizards driven by the static entities NewHireEditStep and HR1ChangeRequestEditStep, with named values in the edit blocks.

11/18/2026

  • New widget: MessageBanner for errors, warnings and information (pale tint, colored left edge, icon, optional title and timestamp). It replaces the red text and alert boxes in the detail blocks. Custom widgets
  • StickyPageHeader has a banner row (Message, MessageTitle, MessageDateTimeStamp, MessageVariant, MessageExtendedClass): a failed save’s error shows there and stays in view while the page scrolls. Message = detail + “ (hostCode – hostMessage)”. Its back event is BackClicked. Custom widgets · Template
  • TS0122 no longer has a one-click override button: the message says to try again with Override Exceptions, and the user switches the toggle and saves again. Template
  • New widget: ExceptionHandlingToggle, the Return | Override Exceptions button group as a block (Value, ValueChanged). Custom widgets
  • New theme classes: ds-list-header / ds-list-header-actions for a list’s top bar, and the ds-banner* classes behind MessageBanner. Theme classes · List template

11/16/2026

  • No made-up descriptions. A code the API returns without a description shows as the code alone (“C”), never text built from it in OutSystems (the templates said “C → Checking”; removed). HR1 and New Hire, which store only codes, look descriptions up with CodeTableText / CodeTableDropdown. List template · Details/Edit template
  • New widget: FromToInput, the field row of the HR1 Change Request edit form: current value with a pencil, the new value’s input under it while editing. Note its number rule (3 decimal places, and it can catch numeric codes). Custom widgets
  • New tab: Payroll Controls (Payroll). One block, one Update, for four LifeView screens that edit the same record: Print Pay Stubs, Check Distribution, Mail W2 Form and Print Time Sheets. It replaces the Check Distribution and Time Sheet Control buttons on Payroll Status. Payroll Controls · The tab
  • Payroll Controls endpoint built: PayPayrollControls_Get and PayPayrollControls_Put (one colToken for all four controls; blank = unchanged; the answer carries controls + updated[], a failure failedControl). Not yet live-confirmed. Payroll Controls
  • New: List Screen Template. One gateway list built to the standard (the Direct Deposits tab): app-table, EffectiveDateFilter, the row buttons and APIPagination with its loading, empty and error states, plus how a list behaves and how its call is wired. Hover or click any part. List Screen Template
  • List columns: every column left-aligned, header and cells, dates and amounts too, at the default width. No widths or alignment classes. The table

11/15/2026

  • Icons are Phosphor 2.0 (ODC’s Icon widget). The button standard now gives Phosphor names: download-simple, floppy-disk and magnifying-glass replace the old Font Awesome-style names; Edit stays pencil. Button standard
  • CodeTableText shows “Code - Description” too, from a live lookup. Which one: CodeDescriptionConcat when the GET returns the code and its description (every API screen); CodeTableText only where just the code is stored (HR1 and New Hire). CodeTableText · CodeDescriptionConcat
  • StickyPageHeader: ← Back sits above the title, like a breadcrumb (the Custom widgets demo showed it beside the title). Custom widgets

11/13/2026

  • Start page reorganized: HR, Payroll and Benefits screens, the review checklist and these updates each have their own page. Checklist items now link to the widget, button or template section that explains them. Review checklist
  • Coded values show “Code - Description” in View, as LifeView does (“10000 - CITY OF LONG BEACH”), not the description alone: the CodeDescriptionConcat block with the code and the description the GET returns. Every mockup shows it. Custom widgets
  • Renamed blocks: CodeDescriptionExpression → CodeDescriptionConcat, DateExpression → DateFormat. CodeDescriptionConcat · DateFormat
  • StickyPageHeader is the header of every detail and edit screen (replaces FloatingActionButtons, which is gone): Title (mandatory), Subtitle and BackLabel (optional; blank = “Back”) inputs, ← Back built in (handle its event with the screen’s back action), the buttons in ButtonPlaceholder. Piloted on TaxControl_Detail. Custom widgets · Template
  • No Save button. Update saves in place, Add saves a new record; a screen shows only what its endpoint supports (Add · Update, Update alone, or Add alone). In-form buttons (Add, Update, Previous, Next) stay plain buttons, since block buttons don’t run the form’s validation; ButtonUpdate is to be removed, ButtonAdd stays for lists. Button standard
  • New blocks ButtonSearch / ButtonReset for filter rows, icon then text like every button: Search with a magnifying glass, Reset with the same prohibit icon as Cancel. EffectiveDateFilter uses them and only searches when Search is clicked. ButtonSearch / ButtonReset · EffectiveDateFilter
  • Sorted table headers in an app-table keep white text; the sorted column is bold with a white underline (LongBeachAdmin theme). Review checklist
  • Rollout list: where each block is still needed, from an AI audit of the app (not yet checked). Custom widgets

11/12/2026

  • Detail header and actions: View: Edit. Editing: Return | Override Exceptions · Delete | Cancel · Add · Update. The exceptions toggle replaces the TS0122 dialog. Template
  • ← Back is a link (“← Back to Check History”), not a button. Button standard
  • Lists: every table has the app-table class (primary-color header, named by its theme token, never a value). APIPagination has an error state (IsError, ErrorMessage). APIPagination
  • Code tables: CodeTableDropdown is edit-only; CodeTableText only in the HR1 and New Hire requests. Null dates show blank. CodeTableDropdown · CodeTableText
